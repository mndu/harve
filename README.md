# HARVE — EMNLP 2026 project page

Website: https://mndu.github.io/harve/

A static research page using the same layout as SAEExplainer, UAV, and Rep2Text: centered paper metadata, bracketed links, the algorithm framework before Overview, and white panels for Overview, Results, and BibTeX.

Results retain one comparison from the supplied paper: the model-specific target gold-preference rates against the original reward models and the stronger fine-tuning baseline from Table 2. All displayed values and author details were checked against `3100_HARVE_Hacking_Aware_Rewar.pdf`.

Open `index.html` locally to preview. No build process is required.
